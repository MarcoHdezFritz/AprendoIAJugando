# Aprendo IA Jugando en Santiago

## Descripción

Aprendo IA Jugando en Santiago es una aplicación móvil educativa gamificada desarrollada para Triskeledu SpA. Su objetivo es fomentar el aprendizaje sobre inteligencia artificial mediante actividades interactivas y la exploración de distintos puntos turísticos de Santiago.

La aplicación combina geolocalización, códigos QR, recompensas y contenido educativo para entregar una experiencia de aprendizaje interactiva.

## Funcionalidades implementadas

- Registro e inicio de sesión de usuarios.
- Dashboard principal con navegación entre módulos.
- Mapa turístico de Santiago con geolocalización.
- Visualización de puntos turísticos.
- Escaneo de códigos QR asociados a puntos turísticos.
- Sistema de recompensas por escaneo de códigos QR (+10 puntos).
- Captura de selfies turísticas mediante cámara frontal (+100 puntos).
- Registro de actividades e historial.
- Colección de puntos turísticos.
- Visualización del progreso del usuario.
- Perfil del jugador.
- Módulos de administración y gestión de contenido.

## Tecnologías utilizadas

- Kotlin.
- Android Studio.
- Jetpack Compose.
- Material Design 3.
- SQLite para almacenamiento local.
- CameraX para acceso a la cámara.
- Google ML Kit para lectura de códigos QR.
- OpenStreetMap / osmdroid para visualización de mapas.
- Geolocalización del dispositivo Android.

## Recursos nativos utilizados

- Cámara del dispositivo para capturar selfies y escanear códigos QR.
- GPS / geolocalización para ubicar al usuario en el mapa.

## Instalación y ejecución

1. Clonar este repositorio.
2. Abrir el proyecto desde Android Studio.
3. Esperar la sincronización de Gradle.
4. Conectar un dispositivo Android o iniciar un emulador.
5. Ejecutar la aplicación desde Android Studio.
6. Conceder los permisos necesarios para utilizar la cámara y la ubicación.
